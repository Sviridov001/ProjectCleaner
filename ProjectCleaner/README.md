# Project Cleaner — Add-On for ArchiCAD 26 / 28 (v1.7.4)

Плагин для очистки и анализа проектов ArchiCAD. Меню **Project Cleaner** разбито на тематические подменю:

- **Очистка проекта** — виды, библиотека, слои, основные макеты
- **Анализ выделения** — площадь штриховок, длина линий
- **Создание из штриховок** — зоны, перекрытия
- **Размеры стен** — цепочка проёмов, цепочка толщин
- **Сервис** — показать/скрыть панель, об аддоне

## Функции

### Очистка
- **Скан/удаление неиспользуемых видов** — поиск видов View Map без ссылок. При подтверждении — удаление (необратимо)
- **Скан/удаление неиспользуемых элементов библиотеки** — поиск неиспользуемых GDL-объектов во встроенной библиотеке. При подтверждении — удаление с опцией «оставить .gsm на диске»
- **Скан неиспользуемых слоёв** — поиск слоёв без элементов. При подтверждении — переименование с префиксом `_null_` (безопасно, элементы сохраняются)
- **Скан неиспользуемых основных макетов** *(v1.2)* — поиск основных макетов, не назначенных ни одному листу. При подтверждении — переименование с префиксом `_null_` (`layoutName` + `uName` в Книге макетов)

### Расчёт (по выделению на плане)
- **Площадь штриховок** — площадь выделенных штриховок по типам (черновая/разрез/покрытие) с копированием в буфер. Учитывает штриховки, выбранные и рамкой, и кликом (дедуп по `guid`)
- **Длина линий** — суммарная длина выделенных линий/дуг/полилиний
- **Создание зон из штриховок** *(v1.1)* — создаёт по зоне на каждую выделенную штриховку (контур копируется, внутри `ACAPI_CallUndoableCommand`)
- **Создание перекрытий из штриховок** *(v1.3)* — создаёт по перекрытию на каждую выделенную штриховку (контур 1-в-1 с отверстиями и дугами, толщина/материал из настроек, этаж как у штриховки)

### Размеры (по выделению на плане)
- **Цепочка размеров проёмов** *(v1.4)* — проставляет цепочку размеров по проёмам выделенных стен (начало стены → косяки → конец). Косяки привязываются ассоциативно к углам проёма (`WindHole`/`DoorHole`), при неудаче — static-цепочка
- **Цепочка толщин стен** *(v1.5)* — цепочка толщин и расстояний выделенных параллельных стен (грани через `offsetFromOutside`, допуск параллельности ~0.5°)

### Прочее
- **Статистика проекта** — сводка количества элементов по типам (стены, колонны, окна, зоны и т.д.) + число слоёв. Показывается вторым окном после **Об аддоне**
- **Об аддоне** — версия и список функций (v1.7)

### Интерфейс
- **Панель инструментов** *(v1.6)* — горизонтальная полоса с 11 иконками 24×24: виды, библиотека, слои, макеты, площадь, длина, зоны, перекрытия, размеры проёмов, толщины стен, об аддоне. Подсказки по наведению, значки кроме «Об аддоне» серые вне плана этажа
- **Показать/Скрыть панель инструментов** — подменю **Сервис**
- Доступна через **Окно → Панели → Project Cleaner**

## Установка

1. Скопируйте `ProjectCleaner.apx` в любую папку
2. В ArchiCAD: **Файл → Менеджер дополнений → Добавить**
3. Укажите путь к `ProjectCleaner.apx`
4. Перезапустите ArchiCAD

## Важные замечания

- Операции удаления видов и библиотечных элементов **необратимы** (Undo не работает, публикации Publisher не проверяются)
- Рекомендуется резервная копия проекта перед удалением
- Элементы с префиксом `_null_` (слои, основные макеты) — кандидаты на ручное удаление через менеджеры атрибутов/книги макетов

## Сборка

- APIDevKit 26, CMake 4.3.1, VS 18 (v145 — снят лимит `_MSC_VER` в `Definitions.hpp:185`)
- Генератор: `Visual Studio 18 2026` x64
- `cmake -S ProjectCleaner -B build -G "Visual Studio 18 2026" -A x64 && cmake --build build --config Release --target AddOn`
- Выход: `build/Release/ProjectCleaner_AC26.apx` → **ArchiCAD должен быть закрыт** (иначе LNK1104)
- ArchiCAD 28: `cmake -S ProjectCleaner -B build28 -G "Visual Studio 18 2026" -A x64 -DAC_API_DEVKIT_DIR=C:/Dev/APIDevKit-28 && cmake --build build28 --config Release --target AddOn`
  результат: `build28/Release/ProjectCleaner_AC28.apx` (имя файла формируется автоматически: `<имя>_AC<версия ArchiCAD>.apx`)

## История версий

- **v1.7.4** — теперь размеры стен ассоциативными (привязаны к граням стен): при изменении стен размер автоматически обновляется.
- **v1.7.2** — в «Цепь толщин стен бы» позиция линии размера запрашивается точкой на плане (по умолчанию — среднее между центров выделенных стен); после создания размера выделение стен сбрасывается и остается выделен только новый размер
- **v1.7.1** — поддержка ArchiCAD 28 (`ProjectCleaner_AC28.apx`): порт на типизированный API (`ACAPI_Navigator_*`, `ACAPI_LibraryManagement_*`, `ACAPI_MenuItem_*`, `ACAPI_ProjectOperation_CatchProjectEvent`, строгий `API_AttributeIndex`) через слой совместимости `ProjectCleanerCompat.hpp`; сборки для 26 и 28 из одного исходника
- **v1.7** — меню разбито на тематические подменю (5 ресурсов `STR#` 32500/32510/32520/32530/32540 с общим заголовком «Project Cleaner»; обработчик различает меню по `menuResID`)
- **v1.6** — панель инструментов с иконками вместо текстовых кнопок (горизонтальная полоса 420×34, 11 иконок GICN 24×24, подсказки через `PanelToolTipRequested` + STR# 32503)
- **v1.5** — цепочка толщин параллельных стен (грани через `offsetFromOutside`, static-цепочка), меню 12, кнопка палитры 11
- **v1.4** — цепочка размеров проёмов (ассоциативные косяки через `WindHole`/`DoorHole` + static-фолбэк), меню 11, кнопка палитры 10
- **v1.3** — создание перекрытий из штриховок, меню 8, кнопка палитры 9
- **v1.2** — скан основных макетов (`_null_` в `layoutName`+`uName`, `ucscpy` + `CallUndoableCommand`, DB-ошибка -2130313215 игнорируется), About+Stats вторым окном, кнопка палитры 4 — макеты
- **v1.1** — создание зон из штриховок (`CallUndoableCommand` фикс -2130312307), версия в About
- **v1.0** — виды, библиотека, слои (`_null_` + счётчик), площадь, длина, палитра, статистика
