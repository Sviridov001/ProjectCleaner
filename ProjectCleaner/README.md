# Project Cleaner — Add-On for ArchiCAD 26 (v1.2)

Плагин для очистки и анализа проектов ArchiCAD. Меню: **Project Cleaner → Очистка проекта**.

## Функции

### Очистка
- **Скан/удаление неиспользуемых видов** — поиск видов View Map без ссылок. При подтверждении — удаление (необратимо)
- **Скан/удаление неиспользуемых элементов библиотеки** — поиск неиспользуемых GDL-объектов во встроенной библиотеке. При подтверждении — удаление с опцией «оставить .gsm на диске»
- **Скан неиспользуемых слоёв** — поиск слоёв без элементов. При подтверждении — переименование с префиксом `_null_` (безопасно, элементы сохраняются)
- **Скан неиспользуемых основных макетов** *(v1.2)* — поиск основных макетов, не назначенных ни одному листу. При подтверждении — переименование с префиксом `_null_` (`layoutName` + `uName` в Книге макетов)

### Расчёт (по выделению на плане)
- **Площадь штриховок** — площадь выделенных штриховок по типам (черновая/разрез/покрытие) с копированием в буфер
- **Длина линий** — суммарная длина выделенных линий/дуг/полилиний
- **Создание зон из штриховок** *(v1.1)* — создаёт по зоне на каждую выделенную штриховку (контур копируется, внутри `ACAPI_CallUndoableCommand`)

### Прочее
- **Статистика проекта** — сводка количества элементов по типам (стены, колонны, окна, зоны и т.д.) + число слоёв. Показывается вторым окном после **Об аддоне**
- **Об аддоне** — версия и список функций (v1.2)

### Интерфейс
- **Палитра команд** — 8 кнопок: виды, библиотека, слои, макеты, площадь, длина, зоны, об аддоне. Кнопки кроме «Об аддоне» активны только на плане этажа
- **Показать/Скрыть палитру** — пункт меню 8
- Доступна через **Окно → Панели → Project Cleaner**

## Установка

1. Скопируйте `ProjectCleaner.apx` в любую папку
2. В ArchiCAD: **Файл → Менеджер дополнений → Добавить**
3. Укажите путь к `ProjectCleaner.apx`
4. Перезапустите ArchiCAD

## Важные замечания

- Операции удаления видов и библиотечных элементов **необратимы** (Undo не работает, публикации Publisher не проверяются)
- Рекомендуется резервная копия проекта перед удалением
- Элементы с префиксом `_null_` (слои, основные макеты) — кандидаты на ручное удаление через менеджеры атрибутов/книги макетов

## Сборка

- APIDevKit 26, CMake 4.3.1, VS 18 (v145 — снят лимит `_MSC_VER` в `Definitions.hpp:185`)
- Генератор: `Visual Studio 18 2026` x64
- `cmake -S ProjectCleaner -B build -G "Visual Studio 18 2026" -A x64 && cmake --build build --config Release --target AddOn`
- Выход: `build/Release/ProjectCleaner.apx` → **ArchiCAD должен быть закрыт** (иначе LNK1104)
