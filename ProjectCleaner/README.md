# Project Cleaner — Add-On for ArchiCAD 26

Плагин для очистки и анализа проектов ArchiCAD.

## Функции

### Очистка
- **Скан/удаление неиспользуемых видов** — поиск видов View Map, на которые нет ссылок. При подтверждении — удаление (необратимо)
- **Скан/удаление неиспользуемых элементов библиотеки** — поиск неиспользуемых GDL-объектов. При подтверждении — удаление с опцией «оставить .gsm на диске»

### Слои
- **Скан неиспользуемых слоёв** — поиск слоёв без элементов. При подтверждении — переименование с префиксом `_null_` (безопасно, элементы сохраняются)

### Статистика
- **Статистика проекта** — сводка количества элементов по типам (стены, колонны, окна и т.д.)

### Расчёт
- **Площадь штриховок (выделение)** — расчёт площади выделенных штриховок по типам
- **Длина линий (выделение)** — расчёт суммарной длины выделенных линий/дуг/полилиний

### Интерфейс
- **Показать/Скрыть палитру** — плавающая панель с быстрыми кнопками
- Доступна через **Окно → Панели → Project Cleaner**

## Установка

1. Скопируйте `ProjectCleaner.apx` в любую папку
2. В ArchiCAD: **Файл → Менеджер дополнений → Добавить**
3. Укажите путь к `ProjectCleaner.apx`
4. Перезапустите ArchiCAD

## Важные замечания

- Операции удаления видов и библиотечных элементов **необратимы** (Undo не работает)
- Рекомендуется резервная копия проекта перед удалением
- Наборы публикации (Publisher) не проверяются
- Слои с префиксом `_null_` можно удалить вручную через меню атрибутов
